# Ревью

Провести ревью в двух сценариях:

1. Беглое (скрипт, для многократного использования, но по потребующий расширения в дальнейшем)
2. Глубокое (инициирующий скрипт, который в дальнейшем планируется развить в инструмент/сервис)

В комментариях ревью соответственно пометки "Критично" - для беглого ревью, "Можно лучше" - для глубокого. Допускаются предложения добавления новых модулей etc.
